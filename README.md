# TAA Vet - Terapias Asistidas con Animales

Este proyecto corresponde a una actividad desarrollada en Java durante el Módulo 4. Consiste en una aplicación de escritorio orientada al registro y seguimiento de terapias asistidas con animales, utilizando estructuras de datos como List, Set y Map.

## Descripción del proyecto

La aplicación permite registrar pacientes, asociarlos a un tipo de discapacidad o condición, seleccionar el tipo de terapia asistida y asignar un animal participante dentro del proceso terapéutico.

Además, permite registrar sesiones por paciente, ingresando datos relacionados con interacción social, regulación emocional y motricidad fina. Con esta información, el sistema calcula un promedio de progreso y lo muestra mediante una barra animada en el tablero.

## Funcionalidades principales

- Registro de pacientes.
- Selección del tipo de discapacidad o condición.
- Selección del tipo de terapia asistida con animales.
- Asignación de animal asistente.
- Registro de sesiones por paciente.
- Evaluación de interacción social, regulación emocional y motricidad fina.
- Cálculo del promedio de la última sesión.
- Visualización de pacientes registrados en una tabla.
- Visualización de sesiones registradas en una tabla.
- Uso de una barra de progreso animada para representar la evolución del paciente.
- Visualización de datos únicos mediante Set.
- Organización y relación de información mediante List, Set y Map.

## Uso de List, Set y Map

En este proyecto se aplicaron distintas estructuras de datos para organizar la información.

La estructura List se utilizó para almacenar registros de pacientes y sesiones, permitiendo mantener una colección ordenada de los datos ingresados.

La estructura Set se utilizó para trabajar con datos únicos, evitando repeticiones y permitiendo visualizar información sin duplicados.

La estructura Map se utilizó para relacionar datos entre sí, por ejemplo asociando pacientes con sus sesiones o información correspondiente.

## Contexto del proyecto

El tema elegido fue terapias asistidas con animales, ya que permite aplicar conocimientos de programación a un contexto relacionado con el área veterinaria y el bienestar humano-animal.

Este enfoque permite representar cómo una aplicación puede apoyar el registro de información, seguimiento de sesiones y revisión de avances en pacientes que participan en terapias con animales.

## Descripción de la interfaz

La aplicación cuenta con una interfaz gráfica organizada en pestañas:

1. Registro Paciente: permite ingresar los datos principales del paciente, tipo de discapacidad, terapia y animal asistente.
2. Registrar Sesión: permite seleccionar un paciente y registrar una sesión con indicadores de progreso.
3. Tableros: muestra las tablas con pacientes y sesiones, además de una barra de progreso animada que representa el promedio de la última sesión registrada.
