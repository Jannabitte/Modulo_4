# Módulo 4 - Actividades realizadas M4.

Este repositorio reúne diferentes trabajos desarrollados durante el Módulo 4 del curso Java Full Stack.

Para mantener el orden, cada actividad o proyecto se encuentra en una rama distinta. 
De esta manera, los trabajos no se mezclan entre sí y cada uno puede revisarse de forma independiente.

## Organización del repositorio

- `main`: rama principal del repositorio.
- `cajero-automatico-swing`: proyecto de cajero automático desarrollado en Java Swing.

## Objetivo

El objetivo de este repositorio es organizar los ejercicios y proyectos realizados en el módulo,que no los pude subir en el momento realizado, aplicando conceptos de programación en Java, estructura de clases, lógica de validación, uso de interfaces gráficas y control de versiones con Git y GitHub.

## Herramientas utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub
