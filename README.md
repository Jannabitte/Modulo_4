# Procesador de Encuestas Editable y/o Simulada

Este proyecto corresponde a una actividad desarrollada en Java durante el Módulo 4. El objetivo principal fue crear una aplicación gráfica que permitiera trabajar con encuestas personalizadas o simuladas, aplicando el uso de colecciones, String y Math.

El sistema permite ingresar nombres de opciones y votos, procesar los datos, calcular resultados y mostrar un gráfico simple de barras para visualizar la información de manera más clara.

## Descripción del proyecto

La aplicación consiste en un procesador de encuestas donde el usuario puede ingresar 5 nombres y sus respectivos votos. Estos datos pueden representar distintas situaciones, por ejemplo videojuegos favoritos, asistencias de un equipo, preferencias de usuarios u otros casos similares.

Una vez ingresada la información, el sistema analiza los datos y muestra un resumen con el total de votos, el porcentaje por cada opción, la opción más votada y una representación visual mediante un gráfico de barras.

El proyecto fue desarrollado con una interfaz gráfica en Java, buscando que el resultado fuera más visual, ordenado y fácil de entender.

## Funcionalidades principales

- Ingreso de 5 nombres u opciones de encuesta.
- Ingreso de cantidad de votos por cada opción.
- Simulación de datos de ejemplo.
- Visualización de resultados y análisis.
- Cálculo del total de votos emitidos.
- Cálculo de porcentaje por cada ítem.
- Uso de `Math.round` para redondear porcentajes.
- Identificación de la opción más votada.
- Visualización de los resultados mediante un gráfico simple de barras.
- Opción para limpiar los datos ingresados.
- Opción para salir de la aplicación.

## Conceptos aplicados

En este proyecto se aplicaron distintos conceptos trabajados durante el módulo.

### Uso de String

Se utilizó `String` para manejar los nombres ingresados por el usuario. Estos nombres pueden representar opciones de una encuesta, como videojuegos, productos, integrantes de un equipo u otros elementos definidos por el usuario.

El uso de String permite trabajar con texto, mostrarlo en la tabla, analizarlo y representarlo posteriormente en los resultados.

### Uso de Math

Se utilizó la clase `Math` para realizar cálculos dentro del análisis de datos. En especial, se aplicó `Math.round` para redondear los porcentajes obtenidos según la cantidad de votos.

Esto permitió mostrar resultados más claros y fáciles de interpretar para el usuario.

### Uso de Colecciones

Se utilizaron colecciones para almacenar y organizar la información ingresada en la encuesta. Esto permite manejar varios datos relacionados entre sí, como nombres y votos, sin depender de variables individuales para cada elemento.

Las colecciones ayudan a que el programa sea más ordenado, flexible y fácil de ampliar.

## Descripción de la interfaz

La aplicación cuenta con una interfaz gráfica dividida en tres secciones principales:

1. **Ingreso de nombres y votos:**  
   En esta sección se ingresan las opciones de la encuesta y la cantidad de votos correspondiente a cada una.

2. **Resultados y análisis:**  
   En esta sección se muestran los datos procesados, incluyendo el total de votos, porcentajes por ítem y la opción más votada.

3. **Gráfico simple de barras:**  
   En esta sección se representa visualmente la cantidad de votos mediante barras, facilitando la comparación entre las distintas opciones.

Además, la aplicación cuenta con botones para simular datos de ejemplo, ver resultados, limpiar la información y salir del programa.
